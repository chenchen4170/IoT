## 技术栈 (Tech Stack)

- 构建：Vite 8.3.5
- 包管理器：npm 10.9.4

### 核心语言与框架
- 语言：TypeScript 6.0.3
- 前端框架：React 19.3.1

- UI 组件库：Ant Design 6.7.0

### 测试
- 测试框架：Vitest + Testing Library / Playwright (E2E)
