# prd

## 需求背景与目标

- 产品分类CRUD

## 用户故事与场景

- 产品分类为具体产品的大类，用于在添加设备页面分类使用

## 功能详述与业务逻辑

- web页面增加“产品分类”菜单
- 新增产品分类
    - 支持选择父节点
    - 必填：分类编码，分类名称，分类描述
- 查询产品分类
    - 默认按照sort_order排序
    - 点击产品分类，展示产品分类详情
- 更新产品分类
    - 更新基本信息
    - 更新排序
- 删除产品分类
    - 产品分类已关联数据，则弹出提示
    - 无关联数据才允许删除
